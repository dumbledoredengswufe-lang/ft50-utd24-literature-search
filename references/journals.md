# FT50 与 UTD24 期刊名录及官网（2026-09 核实）

> - **FT50**：《金融时报》商学院研究排名 50 刊，现行名单自 2017 年沿用；FT 已于 2025-10 启动修订评审，2026 年名单可能调整，使用前可核对 FT 官方最新发布。
> - **UTD24**：德克萨斯大学达拉斯分校商学院排名 24 刊，名单稳定。
> - UTD24 中 23 种与 FT50 重合，仅 **INFORMS Journal on Computing** 为 UTD24 独有。
> - 各刊官网首页均有 **Issues / All Issues / Volumes & Issues** 标签，可浏览每一期目录、文章标题与摘要。

## 各出版平台浏览各期目录的路径
| 平台 | 操作路径 |
|------|----------|
| ScienceDirect (Elsevier) | 期刊页 → Issues → 按卷/期浏览，每篇显示标题 + Abstract |
| Wiley Online Library | 期刊页 → Browse / All issues，文章页直接展示 Abstract |
| INFORMS Pubsonline | 期刊页 → Browse → 按 Volume/Issue，摘要免费可见 |
| SAGE Journals | 期刊页 → All Issues |
| Oxford Academic | 期刊页 → Browse all issues |
| Springer Link | 期刊页 → Volumes and issues |
| Cambridge Core | 期刊页 → Browse by volume |
| AOM / AAA / AEA / UChicago / APA / T&F | 期刊页均有 Issues / Browse / All Issues 入口 |

★ = 同时属于 UTD24。合计 51 种（FT50 的 50 种 + UTD24 独有的 INFORMS Journal on Computing）。
